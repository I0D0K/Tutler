# Tutler

Tutler 是一款面向 Windows 的本地游戏、视频与图片管理器。它把散落在硬盘各处的游戏可执行文件、视频与图片集中到一个界面中，支持启动、分类、收藏与搜索，所有数据保存在本机，离线可用。

## 功能特性

**游戏库**
- 手动添加游戏，或递归扫描指定目录自动发现可执行文件
- 自动过滤 Unity 崩溃处理器、卸载器、运行库安装器等辅助程序
- 自动提取 EXE 内嵌图标作为封面，也可手动选择封面图片
- 识别 Steam 已安装游戏（读取 appmanifest 与库文件夹），支持自动下载商店封面
- 按名称、路径、标签进行容错搜索（支持部分匹配与轻微拼写偏差）
- 支持启动参数、分类、标签、备注、收藏
- 启动次数与最近游玩时间记录，并保留启动历史
- 排序方式：最近添加 / 名称 / 最近游玩 / 启动次数

**视频库与图片库**
- 添加任意数量的扫描目录，递归索引常见视频/图片格式
- 视频封面自动生成（需要系统安装 FFmpeg，未安装时降级为占位提示）
- 调用系统默认播放器 / 图片查看器打开文件
- 自定义分类，可按目录批量归入分类
- 移除记录不会删除硬盘上的原始文件

**分类管理**
- 游戏、视频、图片三套独立分类体系
- 支持自定义分类的新增、删除与排序
- 删除分类时相关资源回退到默认分类或无分类

**界面与交互**
- 深色 / 亮色 / 跟随系统三种主题，可自定义强调色
- 自绘无边框标题栏与窗口控制按钮
- 响应式卡片网格，随窗口宽度自动调整列数
- 侧边栏资源库互斥展开，带高度动画
- 应用内轻量通知，不打断操作
- 中文 / 英文界面（切换后需重启生效）

**数据管理**
- CSV 导入 / 导出游戏清单
- 支持关闭按钮行为自定义（询问 / 最小化 / 直接退出）

## 环境要求

- Windows 10 / 11（主要目标平台；部分功能在非 Windows 系统上不可用）
- Python 3.10 及以上
- PySide6
- 可选：psutil
- 可选：FFmpeg（加入 PATH 后可为视频生成封面帧）

## 安装与运行

1. 获取代码

   git clone <repository-url>
   cd tutler

2. 创建虚拟环境（推荐）

   python -m venv .venv
   .venv\Scripts\activate

3. 安装依赖

   pip install PySide6
   pip install psutil          # 可选

4. 启动

   python main.py

程序图标使用同目录下的 tutler-logo.png 与 tutler.ico；若文件缺失，界面会退化为文字标识，不影响使用。

## 使用说明

### 添加游戏
点击「添加游戏」填写名称与 EXE 路径；选择 EXE 后会自动提取图标作为封面预览。也可点击「扫描目录」选择根目录，程序会列出所有候选 EXE，勾选后批量导入。扫描结果可能包含启动器或组件，请自行确认主程序。

### 识别 Steam 游戏
点击「识别 Steam」会自动搜索注册表与常见安装位置中的 Steam 库，读取已安装游戏并尝试匹配主程序。可在「应用设置 → Steam」中手动指定 Steam 安装路径，并控制是否自动下载封面、是否在启动时自动识别。

### 视频库 / 图片库
切换到对应资源库后，点击「添加视频目录」/「添加图片目录」选择文件夹。若当前正处于某个自定义分类页面，新扫描到的文件会自动归入该分类。分类可在每张卡片上单独修改。

### 分类管理
左侧「游戏分类」展开后可新增自定义分类；点击「排序/管理游戏分类」可调整顺序或删除自定义分类。视频与图片库各自有独立的管理入口。

### 导入与导出
导出会把当前游戏库写为 UTF-8-BOM 的 CSV，包含名称、路径、启动参数、分类、标签、备注、封面、收藏、启动次数、最近游玩、Steam AppID、安装目录等字段。导入时仅要求 name 与 exe_path 两列，重复路径自动跳过。

## 数据存储位置

所有数据保存在本机用户目录下，不会写入游戏安装目录：

%LOCALAPPDATA%\GameShelf\
├── gameshelf.db            # SQLite 数据库
├── covers\                 # 封面缓存（含 Steam 封面与 EXE 图标）
├── video_thumbnails\       # 视频封面缓存
└── icon_extract_debug.log  # 图标提取诊断日志

游戏文件本身不会被复制、移动或删除；从库中移除记录仅删除数据库条目。

## 项目结构

main.py      # 主程序：数据库、扫描、界面、主题与业务逻辑
i18n.py      # 界面文案翻译
tutler-logo.png / tutler.ico  # 应用图标

## 注意事项

- 首次识别 Steam 游戏时需要联网下载封面；断网时仍可正常导入，仅封面缺失。
- 封面会被复制到 Tutler 数据目录，原图片移动后不影响显示。
- 扫描大容量目录可能耗时较长，扫描过程在后台线程执行，不会阻塞界面。
- 无边框窗口的边缘缩放手感依赖 Windows 原生消息处理，非 Windows 平台可能表现为普通窗口。
